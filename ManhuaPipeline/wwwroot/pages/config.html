image 图片模型配置（资产卡 / 画布出图）

image 出图渠道（可配多个）

可以配多个渠道并存（中转 / 方舟 / 302.ai …）。标了「默认」的那条是全局默认： 资产卡出图用它，画布节点在节点面板里没单独挑也用它 —— 画布里每个节点还能单独指定用哪个渠道。 填中转站的 base 地址即可（如 https://xxx.com/v1），只填域名会自动补 /v1； 请求先走 /images/generations，不通会自动回退 /chat/completions。 改地址或名字时 API Key 留空即表示不改动原 Key。 模型下拉里的 ID 是 2026-09-26 从两家接口实测拿到的：展示名跟接口 ID 常常不一致 （直接填 Doubao-Seedream-5.0-pro 这种展示名会 404），所以下拉显示的是习惯叫法、 存进去的是接口真认的 ID。方舟目前没有 Seedream-5.0-lite，换到提供它的渠道时选「自定义」手填。

tune 出图参数

实际出图尺寸：—

档位越高越慢（实测 low≈25s、high≈100s），token 不变。2.5 的 high 只等于上一代的 medium，xhigh 才对得上旧 high。

中转一次只回 1 张，这里按次数依次生成：每张都进「我的资产」图库，第一张回填资产卡。

transparent 会真的出带透明通道的图；jpeg 不支持透明。

当前中转恒返回 PNG，这个参数先存着，换中转后即可生效。
